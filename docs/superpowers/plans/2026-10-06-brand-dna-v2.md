# Brand DNA v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the GitHub-token / GitHub-Actions flow with Vercel Functions so a user pastes a website, watches live progress, and gets a report — no setup in the browser.

**Architecture:** Static frontend (unchanged stack) plus `api/analyze.mjs` (streams NDJSON progress and the final report, reusing `collector/pipeline.mjs`) and `api/share.mjs` (stores / serves ciphertext in Vercel Blob). Reports live in the browser's IndexedDB. Handler logic sits in `server/` as pure functions taking web `Request` and returning `Response`, so tests need no Vercel runtime.

**Tech Stack:** Node 24, plain ES modules, `node --test`, `cheerio`, `fast-xml-parser`, `@vercel/blob` (server), `fake-indexeddb` (dev).

**Spec:** `docs/superpowers/specs/2026-10-06-brand-dna-v2-design.md`

## Global Constraints

- No build step, no framework; frontend is ES modules served as static files.
- Accent `#97C4FF`, text on accent `#0B1F3A`, links `#2F6FD0`, borders `#E6E9EF`, font Roboto with `system-ui, sans-serif` fallback.
- Type scale 14 / 16 / 20 / 28 / 40 px; spacing 4 / 8 / 12 / 16 / 24 / 32 / 48; radius 12 px cards, 8 px controls; responsive to 360 px.
- `/api/analyze` body ≤ 8 KB, `maxDuration` 300 s; `/api/share` ciphertext ≤ 2 MB.
- Function logs never contain brand names, URLs or report content.
- Report schema v1 unchanged; report `id` generated server-side with `newReportId()`.
- Downloaded / exported files carry the note "Downloaded files are not encrypted."

## Review Focus

1. Website that is unreachable or returns non-HTML → report still produced, name falls back to the capitalised domain label (Task 2 test `detectName falls back to domain`).
2. NDJSON chunks split mid-line or stream cut before the final event → client returns "The analysis took too long. Try again." instead of hanging or throwing (Task 5 tests).
3. IndexedDB unavailable (private mode) → library falls back to memory, `persistent: false`, UI shows the can't-save banner (Task 6 test).
4. Shared link with a valid-looking id but wrong key, or blob missing → "This link is incomplete or has expired." (Task 7 test).
5. User-typed name / industry / socials must override detected values (Task 2 / Task 3 tests).

```js
const SEP = /\s+[|–—\-:·]\s+/;
const clip = (s) => (typeof s === 'string' ? s.trim().slice(0, 100) : '');

export function detectName(site, websiteUrl) {
  const fromTitle = clip(site?.title).split(SEP)[0]?.trim();
  for (const c of [site?.org?.name, site?.og?.siteName, fromTitle]) if (clip(c)) return clip(c);
  try {
    const labels = new URL(websiteUrl).hostname.replace(/^www\./, '').split('.');
    const label = labels[0] || 'Brand';
    return label.charAt(0).toUpperCase() + label.slice(1);
  } catch {
    return 'Brand';
  }
}

export function detectIndustry(site, table) {
  if (!site) return 'default';
  const words = [site.title, site.description, ...(site.h1 ?? []), ...(site.h2 ?? [])].join(' ').toLowerCase().split(/[^a-z0-9-]+/);
  const bag = new Set(words.filter(Boolean));
  let best = 'default';
  let bestScore = 1;
  for (const [key, v] of Object.entries(table)) {
    const score = (v.keywords ?? []).filter((k) => bag.has(k)).length;
    if (score > bestScore) { best = key; bestScore = score; }
  }
  return best;
}
```

### Task 4: `/api/analyze` handler and function

**Files:** Create `server/analyze.mjs`, `api/analyze.mjs`, `vercel.json`, `test/server/analyze.test.js`.

**Interfaces:** `handleAnalyze(request, { buildReport, env = {}, newId = newReportId, now = () => new Date(), log = console.log }) → Promise<Response>`. Non-POST → 405. Body > 8192 bytes → 413 `{error}`. Invalid JSON → 400 `{error:'Invalid request.'}`. Validation failure → 400 `{errors}`. Otherwise 200 `application/x-ndjson` stream: every `onProgress` event, then `{type:'report',report}` or `{type:'error',message:'The analysis failed. Try again.'}`.
